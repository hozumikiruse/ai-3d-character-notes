## 需求與已確認範圍

使用既有下載的 Uka 範例模型，在 Godot 輸入中英文指令，透過本機 MotionBricks 生成與播放身體動作。使用者已選定有限指令介面：走、轉身、揮手、蹲、跳及順序組合；不支援的描述須明確拒絕，不冒稱任意自然語言模型。

銀醬造型工作仍暫停，既有素材／模型／工程保留。此 PR 不重新生模、不安裝新權重、不建立伺服器。Uka 保留作者署名；只是範例角色，不是銀醬。

## 已知條件

- `godot-mmd/assets/uka-three-motions.glb` 已有模型、骨架、材質與三組重定向動作，可作播放對照。
- `runtime/motion-env`、`runtime/MotionBricks`、`runtime/motion-trt-cache` 已有本機推理環境。
- MotionBricks 接受四個歷史姿勢與一至四個目標姿勢，非原生 text-to-motion。SOMA 模型不預測手指，不產出臉部表情。
- `assets/source/pr007/primero` 是女性素體參考，缺少完成的權重／材質，不選作本次播放器模型。

## 工作計劃

只推進一個主要驗收目標：輸入一段支援指令，實際生成新動畫並在 Uka 身上播放。

| 步驟 | 工作 | 驗證 |
|---|---|---|
| 1 | 指令語法、順序、參數與拒絕規則 | 解析測試：中英混合、距離、角度、重複次數、未支援／否定描述 |
| 2 | 姿勢規劃及本機推理工作程序 | 實際模型推理、有限值、時間、目標與原始輸出保存 |
| 3 | 獨立 Godot 介面與 Uka 重定向 | 模型可見、骨骼資料吻合、文字輸入、生成狀態、播放暫停／重播／進度 |
| 4 | 順序組合、失敗及關閉流程 | 不誤播舊結果、不凍結 UI、停止本次工作、不遺留推理程序 |
| 5 | 交付啟動入口、使用說明及證據 | 實際畫面截圖、完整輸入至播放測試、來源檔案雜湊保持 |

## 實作原則

- 新增獨立 `godot-motion-text` 工程及 `scripts/pr008_*`，沿用原始 Uka 顯示資料。
- Godot 啟動本機 Python 子程序，以作業 JSON 檔案交換資料；不開 HTTP／TCP 服務、不使用付費 API。
- 生成動作與原本三組範例明確分開，UI 不以讀取既有動畫冒稱生成。
- 文字解析結果先顯示，保存原文與動作計劃；超出範圍、否定及模糊內容不靜默忽略。
- 動作長度／次數／距離有合理上限，避免無限生成。
- 本次不增加手指、表情、頭髮／裙子物理；顯示已知限制。

## 完成條件

至少一段包含位移、轉向與手勢的中文順序指令，及一段英文指令，通過真實本機推理並在 Godot 播放。使用者能自行輸入、再次生成、停止／重播，看到不支援指令的原因。交付時區分功能驗收與動作品質限制。
