# PR-005｜銀醬重新生模候選與有限比較

日期：2026-11-07。狀態：本輪三個候選的下載、本機生成、真實渲染與獨立審查已完成；造型未通過。按「哪個先成功下載就先試哪個」，實際順序為 Hunyuan → TRELLIS → StdGEN。[實測結論與容量](PR-005-RESULTS.md) · [多角度／灰模／疊圖](PR-005-REVIEW.html)。

## 本輪執行順序（優先於下方原候選排序）

**最新調整：按權重與依賴就緒順序執行，GPU 推理仍一次只跑一個模型。** 以下是原定優先順序，現已取消其等待限制。

1. StdGEN：先檢查 Windows 依賴、磁碟與顯存；可行便以正面全身輸入產出研究試樣。官方訓練使用全身，不能沿用頭部裁切試驗來評估它。以 CLI 分階段執行，研究輸出獨立保存。
2. TRELLIS.2 INT8：頭部兩個固定種子，保留原始生成幾何和色彩。
3. Hunyuan3D-2mv：頭部三視圖幾何對照，兩個固定種子。
4. 真實多角度渲染、原圖對照與獨立視覺審查；不改正式 Godot 資產。記錄實際安裝量及未完成／不可行原因。

授權包含上述本機試驗所需下載與執行，沿用既有 ComfyUI；不另建伺服器。StdGEN 的研究用途限制已告知；本次研究試樣不作正式直播資產。

### 實測中發現的轉換問題

Hunyuan3D-2mv seed 42／384 體素解析度已成功生成，推理與輸出約 142.5 秒，觀測整張 GPU 峰值 6776 MiB。原生 ComfyUI Surface Net 輸出為 2,532,014 三角面；有 468,276 條非流形邊和 584,457 條面方向不一致邊，真實渲染可見條紋與破碎。該原始結果保存在 `renders/pr005/hunyuan-42/`，不能因 render profile 回傳 pass 就視為可用。

新增獨立的標準 Lewiner Marching Cubes 節點作轉換對照（Hunyuan 官方也提供此演算法）。保留 seed 42、相同 VAE、384 解析度及 **0.6 等值面閾值**，以避免同時改變生成參數；沒有平滑、雕刻、重建眼睛或覆蓋髮束。先以解析球體驗證閉合性、面方向與體積，再以真實人物結果驗證。這是排查輸出轉換問題，不代表外觀已通過。

轉換對照已完成：MC 版本 2,091,602 三角面，非流形邊 0、邊界邊 0、面方向不一致邊 0，條紋消失。仍有小島、細小退化面／近重合點、部分封閉內表面，以及超過高模檢查上限而未執行的交疊檢查。髮束孔洞、眉眼與瀏海比例仍未通過造型驗收；無 UV、骨架、表情。不能將工具的 `pass: true` 當作可用於 Godot 的成品。

## 需求

使用者認為 PR-004 v2 與 new.png 仍有很大差異，選擇先評估「換 AI 模型重新生成底稿」，以「使用合適、授權允許的動漫底模改造」作後備。維持免費、本機、Windows RTX 4070 12 GB／RAM 32 GB；目標仍是可進 Godot 的銀醬。

## 現況與判斷

- 正式 v1 的骨架、MotionBricks 動作、Godot 管線及備份保留。
- v2 的程序化臉和規則厚髮束未通過造型還原；暫停沿同一方法反覆微調。
- 本機已具備 ComfyUI 原生 TRELLIS.2、Pixal3D 及 Hunyuan3D 多視圖節點與工作流模板。這表示有執行入口，不等於新模型已在本機實測。
- 現有 Pixal3D 使用多視圖 INT8、DINOv3、TRELLIS.2 shape/texture VAE。後三者可供官方 ComfyUI TRELLIS.2 模板共用。
- 原圖是全身三視圖，臉部佔的像素有限；頭部裁切可增加生成網格分配給頭部的比例，但不會憑空補回原圖沒有的細節。

### 首輪實作邊界

1. 從原圖取得一致範圍的頭部參考，先檢查髮頂、下巴和頭頸高度，以及側圖方向；不重新設計銀醬。裁切是輸入預處理；若需生成或改畫圖片，只使用內建 image_gen。
2. TRELLIS.2 先用正面頭部，側、背圖留作獨立檢查。Hunyuan3D-2mv 再使用方向標記正確的三個視圖。
3. 保留未修過的 AI 原始網格。首輪不以程序化通用眼睛、頭型或髮束覆蓋生成結果，以免無法分辨生成器和後處理的影響。
4. 同時看有色渲染與中性材質幾何：貼圖漂亮不能掩蓋錯誤立體，無貼圖的 Hunyuan shape 也不能被誤判成缺少生成能力以外的內容。
5. 比較順序：原圖並排 → 模型單獨觀看 → 側面與 45° → 疊圖。45°無原圖，僅檢查立體連續性；不虛構相似度百分比。
6. 只產出小樣與比較紀錄，不修改正式 Godot 資產。底稿通過後才安排局部接回、拓撲、貼圖、表情及權重工作。
7. 本輪不新增伺服器、雲端付費服務或大型整合包；是否沿用既有已授權 ComfyUI 執行路徑，實作時依既有設定處理。

## 下一個具體動作

本輪已完成，不再追加生成器或換種子。建議後續改從授權適合、具完整臉部拓撲的動漫底模出發，依 new.png 重塑臉、耳及髮束；保留本輪體積與色彩參考，沿用已有 Godot／動畫管線。底模候選及重製範圍另行形成下一份 PR，本輪沒有下載底模或覆蓋可動版。
