# PR-007：Uka MMD → Godot 獨立視覺審查

審查日期：2026-11-07。範圍僅限成熟 Uka 模型的外觀保存，以及揮手、蹲下再站起、原地小跳的截圖證據。

**結論：有限通過管線測試。** Godot 中可辨識同一個 Uka 模型，主要幾何與貼圖保留，三個動作均有合理的關鍵姿勢，跳躍有明確離地證據。這支持繼續使用成熟 MMD 模型驗證轉接管線；不代表完整動作品質或原作渲染風格已驗收，更不代表銀醬已完成或品質達標。

本審查依 `concept-target-visual-gate` 由未參與模型／程式製作的獨立 reviewer 執行。沒有讀取主代理自評；只開啟影像與讀取取樣 metadata，沒有修改模型、材質、程式或截圖。以下「未見」僅適用已列出的可見範圍。

腳底檢查：中立、揮手、蹲姿及跳躍恢復站立的已看樣本，未見明顯鞋底大幅穿入地面；跳起樣本有清楚空隙。陰影偏移、相機投影與小幅鞋底間隙不足以證明精確接地。**不能以這批截圖宣稱全程腳鎖定、零滑步或零漂浮。**

目前未見脫落肢體、反向膝關節、明顯拉爆的肩頸或巨大網格伸展。尾巴與頭髮在樣本中保留完整輪廓，但物理擺動、碰撞與穿插的連續性未驗證。

## UI 證據

動作名稱、選中項、進度、秒數、速度、暫停／重播、角度按鈕均可讀，無明顯文字裁切。畫面明示「Uka 原作者模型，並非銀醬」，也區分原作者站姿與其他動作；這個範圍標示應保留。署名及授權字樣可見，但本審查沒有做授權條款查核。

「動作取樣 3 / 5」等標籤實際與動作選項位置一致，在同一動作的不同時間仍不變，容易被讀成該動作已取了第幾幀。建議改成「動作 3 / 5」，若要表示幀證據則另外顯示取樣編號。UI 按鈕的功能與快捷鍵不能從靜態圖驗收。

## 具體阻礙與下一個最小證據

1. **動態服裝變形**：先修蹲姿與跳前／落地屈膝時的髖部內襯、前衣襬硬片翻出，再重拍相同的正、側、45°低位姿勢。保留原有衣服設計，不應刪去衣襬或改身形以藏問題。
2. **完整動作可用性的證據不足**：補三段連續播放證據，側面保留地面基準，檢查揮手完整次數、開始／結束姿勢、蹲起過渡、起跳與落地接地、腳滑與衣物穿插。此項是尚未驗證，不是已證明播放失敗。
3. **最終外觀保存**：若要宣稱接近原作，需選定並記錄對應的 toon／線條／陰影呈現，補臉與手近景及同姿勢對照。現在的貼圖無光照展示足以辨識外觀資料，尚不能代表原作渲染風格復現。

**可記錄的里程碑：成熟 Uka MMD 模型在 Godot 的外觀資料與三動作關鍵姿勢管線驗證成立，附服裝變形及連續播放證據限制。不可記錄的里程碑：銀醬完成、銀醬品質達標、三動作全程無瑕疵、原作外觀完整復現。**
